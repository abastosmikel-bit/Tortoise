# raw/: per-run outputs

| Files | Included in this release | What |
|---|---|---|
| `*.json` (per run) | yes | metrics for one run: trips, latched classes, lock latency, gaps, reset levels, run info. All summaries are recomputed from these by `../scripts/summarize.py`. |
| `*.csv.gz` | **no** | waveforms resampled every 1 µs (rails, latches, `win`/`lockb`, `ref`, timing lines) |
| `*.cir.gz` | **no** | the exact netlist simulated |
| `*_draws.json` | **no** | Monte Carlo draws (DVTH, KMU, KRC per TFT) for that die |
| `*_end.{dat,cols}`, `fitc10_warm.*` | yes | end states used as warm starts |
| `*.audit.txt` | yes | `rev10/sim/tools/audit.py` output for the stress-audit runs |

The waveforms, simulated netlists and Monte Carlo draws (≈ 87 MB for this campaign) were kept out of the public
release. They are regenerated by re-running the campaign phases ([`REPRODUCE.md`](../../../REPRODUCE.md) §6); every
runner writes them next to the per-run JSON. Re-running a phase whose per-run JSONs exist is skipped, so move the
phase's folder aside first.

Variant 1 outputs are in `raw/<phase>/`; Variant 3 (main design) outputs are in `raw/v3/<phase>/`.
