# Tortoise results index

One row per headline number across the five simulation campaigns and the wrap-up studies (rows `WU-…`, the wrap-up studies,
[`results/wrapup`](results/wrapup/REPORT.md); variants named `candidate-…` there (identifiers `R10.2-…` in file names and JSON keys; [docs/NAMING.md](docs/NAMING.md)) are **candidates, not Tortoise v1.0**). **Simulation only**: ngspice-42, a reconstructed
device corner (`fitc10`), a synthetic dataset; nothing has been measured. Each row names the summary file the number
is read from, the script that writes that summary, and where the per-run data live.

**Checked by** [`tools/check_results_index.py`](tools/check_results_index.py): it reads every summary file named below,
recomputes the shown numbers, and compares them with the Value, N and "CI or range" cells at the precision shown
(`python3 tools/check_results_index.py`; expected result in [`REPRODUCE.md`](REPRODUCE.md) §4).
Summary files are regenerated from the committed per-run JSONs by [`tools/reproduce_summaries.sh`](tools/reproduce_summaries.sh).

Conventions:
- Accuracy = correct of N, invalid runs count as wrong. CI = Wilson 95 % unless stated. "Valid" = exactly one class
  latched and it was the first to trip.
- N = 20 is the fixed 20-sample test subset ([phase3_subset.json](results/fitc10_campaign/summary/phase3_subset.json),
  4 per class); one sample is 5 points. N = 90 is the full test set.
- Campaign folders: `fitc10` = [`results/fitc10_campaign`](results/fitc10_campaign/REPORT.md),
  `weights` = [`results/weights_schemeA`](results/weights_schemeA/REPORT.md),
  `energy` = [`results/energy_host`](results/energy_host/REPORT.md),
  `host v2` = [`results/host_v2`](results/host_v2/REPORT.md), `host v2.1` = [`results/host_v21`](results/host_v21/REPORT.md),
  `wrapup` = [`results/wrapup`](results/wrapup/REPORT.md) (wrap-up studies; WU rows; candidate variants are marked as such and are not Tortoise v1.0).
  Scripts and raw paths are relative to the campaign folder.
- Raw data: per-run `*.json` (metrics) are included; `*.csv.gz` (waveforms), `*.cir.gz` (netlists) and `*_draws.json`
  (Monte Carlo draws) are **not included** in this release and are regenerated by re-running the campaign
  ([`REPRODUCE.md`](REPRODUCE.md) §6).
- Unless stated, the circuit is Variant 3 at `fitc10` with the weights `rev10/eval/F_hw_m4_firstpass.npy`.
